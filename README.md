# 🪞 ミラーコピーアプリ

送信元フォルダの変更を**リアルタイムで監視**し、コピー先フォルダへ
同じ内容を**ミラー転送**するアプリです。専用の Web UI から操作できます。

## 特長

- 送信元の追加・更新・削除をリアルタイムに検知してコピー先へ反映
- 「完全ミラー」モード：送信元で削除されたファイルをコピー先からも削除
- 複数の転送ジョブを登録し、それぞれ個別に開始/停止
- 各ジョブの転送件数・ライブログを Web UI で確認
- 設定はディスクに永続化（再起動後も保持）

## 使い方

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。

1. 「送信元フォルダ」「コピー先フォルダ」の **［参照…］** ボタンを押し、
   ダイアログでフォルダをたどって選択（手入力は不要）
   - 上の階層へ移動・ホームへ移動・新規フォルダ作成も可能
2. 作成したジョブの「監視開始」を押す
3. 送信元のファイルを変更すると、コピー先へ自動でミラーされます

> ⚠️ サーバーが動作しているマシン上のパスを対象にします。
> 「完全ミラー」を有効にすると、送信元から消したファイルはコピー先からも消えます。

## API

| メソッド | パス | 説明 |
|---------|------|------|
| GET | `/api/jobs` | ジョブ一覧 |
| POST | `/api/jobs` | ジョブ作成 `{name, source, dest, deleteOrphans}` |
| DELETE | `/api/jobs/:id` | ジョブ削除 |
| POST | `/api/jobs/:id/start` | 監視開始 |
| POST | `/api/jobs/:id/stop` | 監視停止 |
| GET | `/api/jobs/:id/logs` | ログ取得 |
| GET | `/api/browse?path=` | フォルダ参照（サブフォルダ一覧。省略時はホーム） |
| POST | `/api/mkdir` | 新規フォルダ作成 `{parent, name}` |

## 構成

- `server.js` — Express サーバー（API + 静的配信）
- `lib/mirror.js` — chokidar によるミラー転送ロジック
- `lib/store.js` — ジョブ管理と設定の永続化
- `public/` — Web UI
